# Caracol

Phoenix 1.8 application.

## Quickstart

1. Install dependencies and prepare the database:
   `mix setup`
2. Start the server:
   `mix phx.server`

Open [http://localhost:4000](http://localhost:4000).

## Development Commands

- Run tests: `mix test`
- Run formatting: `mix format`
- Run the full local quality gate: `mix precommit`
